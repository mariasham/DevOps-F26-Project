# Law School Application Tracker Project Site

Created by Maria Shamasna for COMP 4420.

This Node.js and Express website documents the JavaFX Law School
Application Tracker.

## Run the Website

Install Node.js and npm, then open a terminal in the project-site folder.

Install dependencies:

```bash
npm install
```

Start the website:

```bash
npm start
```

Open http://localhost:3000 in your browser.

Stop the server with Ctrl+C.

## Pages

- Home
- Documentation
- Quickstart
- Browse Law Schools
- View Application Details
- Check Application Status
