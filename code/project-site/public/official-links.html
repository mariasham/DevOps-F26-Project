How to Open an Application Link

  1. Launch the Law School Application Tracker.
  2. Double-click a school in the main list to open its details window.
  3. Find the website address shown beside “Application Link.”
  4. Click the “Open Application Link” button.
  5. The school's admissions page opens in your default web browser. An internet connection is required.
  6. Review the school's official application requirements and deadlines.

Return to the Tracker

Switch back to the Java application after viewing the website. Close the details window to choose another school.
