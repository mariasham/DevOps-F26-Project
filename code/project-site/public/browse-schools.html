How to Browse Schools

The main application window displays the available law schools and their application status.

  1. Launch the application using the Quickstart guide.
  2. Find the school list beneath the “Law School Applications” heading.
  3. Read through the school names. Scroll within the list if additional schools extend beyond the visible area.
  4. Click a school’s row to select it.

Available Schools
