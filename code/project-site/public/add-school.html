How to Add a School

  1. Launch the Law School Application Tracker.
  2. Clear any text in the search box.
  3. Click the + button beside the school list.
  4. In the Add Law School window, enter the school's name.
  5. Enter its location and application deadline.
  6. Set its application status to Open or Closed.
  7. Enter the full application website address, including https://.
  8. Click Add to submit the school.
  9. Check the main list for the school you added.

Cancel Without Adding

Click Cancel to close the form without adding a school.
