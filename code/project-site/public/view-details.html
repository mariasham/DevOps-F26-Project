How to Open a School’s Details

  1. Launch the application using the Quickstart guide.
  2. Find the school you want to explore in the main school list.
  3. Double-click the school’s row to open its details window.
  4. Review the application information displayed in the window.
  5. When finished, close the details window using its X button to return to the main school list.

Explore Another School

Return to the main list and double-click another school to view its information.
