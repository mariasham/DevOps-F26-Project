How to Check a School’s Status

  1. Launch the application using the Quickstart guide.
  2. Locate a school in the main school list.
  3. Read the status shown after the school’s name: Open or Closed.
  4. Repeat for other schools to compare their displayed statuses.

Understanding the Status

  • Open: The app lists applications as open.
  • Closed: The app lists applications as closed.

The application uses sample school data. Confirm current application dates and availability on the school’s official website.
