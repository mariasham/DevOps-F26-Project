Quickstart Guide

Home Documentation

1. Check Prerequisites

Install the Java Development Kit (JDK), Apache Maven, and Git before launching the application.

Check that they are available by running:

java -version
mvn -version
git --version

2. Download the Project

Open a terminal and clone the repository:

git clone https://github.com/mariasham/DevOps-F26-Project.git

If you already have the repository downloaded, use your existing project folder.

3. Open the Application Folder

From inside the DevOps-F26-Project folder, open the code folder, which contains pom.xml: 

cd code

4. Launch the Application

Run the following command from the code folder:

mvn javafx:run

Maven downloads the required dependencies on the first run. An internet connection is needed for those downloads. The application opens in a desktop window.

5. Explore the Features

Once the school list appears, follow the feature guides to learn how to use the application.
