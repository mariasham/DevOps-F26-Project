How to Search

  1. Launch the Law School Application Tracker.
  2. Click the text box above the school list.
  3. Type part of a school’s name, such as Emory.
  4. The list filters as you type to show matching schools.
  5. Double-click a result to view its details.
  6. Clear the text box to display the full school list again.
